# Overview

PowerConfigurator is a native Win32/GDI application that replaces Alienware Command Center with a <20MB, zero-background-service, zero-telemetry executable. The **Cyberpunk "NEON DISTRICT" theme** is the flagship visual identity — a night-city terminal aesthetic built on restraint and precision. Pure black void (#050508), razor-thin neon strokes (1px), cyan/magenta/yellow trims, monospace telemetry. No rounded corners, no soft shadows, no decorative circuit lines. Glow is earned by state (hover/active/danger only), never ambient.

**Platform**: Windows 10 19041+ / Windows 11 (adaptive DPI, per-monitor v2)
**Stack**: Pure Win32 C++ (MSVC), GDI rendering, double-buffered, no external UI frameworks
**Constraints**: Binary <20MB, RAM <50MB idle, CPU <1% idle, WCAG 2.2 AA accessible

## Elevation & Depth

**Flat by default** — no shadows, no elevation layers. Depth communicated via:
- Border color shift (dim violet → neon magenta on hover)
- Background lift (`bgCard` → `bgCardHover`)
- Glow halo (3-layer concentric strokes, hover/active/danger only)

**Cyberpunk Glow System**
- Layer 1 (outermost): `#FF00A8` at full radius + 6px
- Layer 2: `#CC0086` at full radius + 4px
- Layer 3 (innermost): `#990065` at full radius + 2px
- Drawn outermost-first, 1px stroke each
- Only on: active profile pill, hovered telemetry cards, danger-state cards

**Scanlines**
- 8×4 pattern bitmap: rows 0-3 transparent, row 3 = `scanlineColor` at 8% alpha
- Applied as final fill pass over client rect via `CreatePatternBrush`
- NOT per-frame line drawing — single `FillRect` with pattern brush

## Do's and Don'ts

### Do
- ✅ Use `Theme::Tokens()` for every color, radius, font, metric
- ✅ Draw through `Theme::Brush()/Pen()/Font()` cache
- ✅ Clip painting to `ps.rcPaint` — partial invalidation only
- ✅ Invalidate only metric card rects on 1s timer tick
- ✅ Apply hardware settings on drag end, not per tick
- ✅ Debounce `SaveSettings()` (1s coalesce)
- ✅ Honor `WM_DPICHANGED` — rescale layout, rebuild fonts
- ✅ Register `TaskbarCreated` — restore tray icon on Explorer restart
- ✅ Clear `g_uiInstance` in `WM_NCDESTROY`
- ✅ Draw focus rings (2px `borderFocus`) on all focusable controls
- ✅ Encode status with glyph + color, never color alone
- ✅ Maintain 44px min hit targets (buttons, sliders, touch targets)
- ✅ Verify contrast per theme at implementation (WCAG 2.2 AA)
- ✅ Gate animation timer — only run while transition active
- ✅ Kill animation if idle CPU >1% (token `animationEnabled=false`)

### Don't
- ❌ No `RGB()` literals outside `Theme.cpp` (except LED user color data)
- ❌ No duplicate drawing primitives (`UI.cpp` → `ModernTheme` only)
- ❌ No global palette reads in primitives (F-03)
- ❌ No Direct2D/Skia/Qt/WinUI — GDI only
- ❌ No background threads/services — single UI thread, 1s timer
- ❌ No glow on everything — hover/active/danger only
- ❌ No decorative circuit lines, hex grids, matrix rain
- ❌ No emoji in production — Segoe MDL2/Fluent glyphs or GDI shapes
- ❌ No full-window `InvalidateRect` on metrics tick
- ❌ No hardcoded layout constants — `Layout::Compute` only
- ❌ No animation that violates <1% idle CPU
- ❌ No empty control stubs — implement or delete (B-09)
- ❌ No partial theme state mixing — `SetTheme` flushes cache + full invalidate
- ❌ No rounded corners in Cyberpunk — razor sharp (2px card, 0px button)
- ❌ No soft shadows — border color shift + glow only

## Acceptance Criteria (from UI_AUDIT.md §10)

1. All 5 themes implemented exactly per spec values
2. Zero hardcoded palette reads outside `Theme.cpp` (`RGB(` grep gate)
3. Single source of drawing primitives (no duplicates)
4. Native-widget mismatch eliminated — every control themed
5. Contrast: all text ≥4.5:1, components ≥3:1 (tables per theme)
6. Focus indicators on all interactive controls (Tab walk visible)
